# StemScore 本地训练方案

当前预训练模型已经覆盖五步流程，第一版不启动无目标训练。先通过用户自己的真实项目审查记录建立错误集，再决定是否微调。这样可以避免用未对齐的 DAW 素材训练出看似收敛、实际更差的模型。

内部回归先采用预训练模型替换和质量门，结果支持继续积累错误集，而不是立即从零训练 WAV→MIDI。后续只有在用户确认的独立测试集仍持续失败且已积累对齐标签后，才启动微调。

## 数据集整理

训练中心只建立清单，不改动源文件。每个文件记录绝对路径、大小、修改时间和 SHA-256。候选组必须补充：数据权利、歌曲/工程 ID、轨道角色、起止对齐、采样率、是否包含混响、训练/验证/测试划分。

切分必须按歌曲或工程进行，不能把同一歌曲的片段同时放入训练集和验证集。增广版本、不同导出格式和同一工程的往返转换都属于同一组，防止数据泄漏。

## 分离模型微调

使用 MSST 自带 `train.py`。先把用户确认的多轨导出为固定结构，再复制当前最佳模型配置，唯一修改数据路径、实验名、batch size 和学习率。RTX 5080 Laptop 16GB 建议从短 chunk、batch size 1 和梯度累积开始；每次实验保留配置、Git 提交、环境锁、随机种子、初始权重哈希和最佳权重哈希。

验证指标至少包含 SDR/SI-SDR、混音重构误差和固定人工试听集。只提高训练损失或单一 SDR 不构成替换生产模型的依据。

## MIDI 模型微调

优先积累已对齐的单轨 WAV + MIDI。MIDI 必须检查速度图、绝对时间、音符重叠、踏板、弯音和鼓通道。针对人声可使用 GAME 的公开训练代码；针对多乐器可使用 YourMT3+ 数据格式；Basic Pitch 官方包用于推理，不应在没有明确训练实现和基准时假装完成微调。

替换模型前，在独立测试集报告 onset F1、onset+offset F1、带 velocity 指标、鼓类逐类 F1，以及 DAW 人工校谱耗时。只有新模型同时通过自动指标和盲听/校谱审查，才更新客户端默认模型。

## WebUI 进度

训练配方 JSON 必须包含：

```json
{
  "cwd": "C:\\path\\to\\MSST-GUI",
  "command": [
    "C:\\path\\to\\MSST-GUI\\env\\python.exe",
    "C:\\path\\to\\MSST-GUI\\train.py",
    "--model_type", "bs_roformer",
    "--config_path", "C:\\path\\to\\dataset\\experiment.yaml"
  ]
}
```

训练中心只允许调用配方 `cwd` 中的 `train.py`，避免网页输入任意系统命令。开始前由用户人工确认数据授权、配置和输出目录；开始后 WebUI 轮询本地状态并显示最近 200 行日志。
