# StemScore 1.0.0-public-rc6

RC6 fixes an MSST inference failure that could appear only after runtime and model installation had already succeeded.

- MVSep Mega 53 Stems v1 no longer writes all 53 temporary WAV files into Windows `%TEMP%` on the system drive.
- The large raw 53-stem cache is written directly to the project directory, on the same volume as the user's project output.
- The temporary staged input file is also created beside the project output instead of on C:.
- The 53-stem path avoids making a second full copy of roughly 4–5 GiB of raw stems.
- Before launching MSST, StemScore checks free space on the project volume and reports a clear minimum-space estimate.
- Legacy MSST temporary work also follows the project volume.
- Child-process failures now include a useful error line in the UI instead of only showing a generic exit code.

Real-machine validation used a 257.84-second, 44.1 kHz stereo source. MVSep Mega 53 Stems v1 produced all 53 stems directly on the E: project volume in about 66 seconds while C: free space remained stable; StemScore then generated the stage-2 vocal and accompaniment artifacts successfully.

Validation: 85 automated tests passed before release preparation.
