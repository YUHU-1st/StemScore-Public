# StemScore 1.0.0-public-rc4

RC4 is a small follow-up to RC3 that closes the last clean-machine repair gap.

- If `ffmpeg` / `ffprobe` is missing, the same **一键修复运行环境** flow now installs a pinned `Gyan.FFmpeg 8.1.2` package through the Windows Package Manager `winget` official index.
- StemScore refreshes the current process with `%LOCALAPPDATA%\Microsoft\WinGet\Links` so the repair can continue without requiring a manual PATH edit.
- The repairable-error detector now recognizes the exact `ffmpeg / ffprobe` message emitted by core runtime validation.
- RC3's MSST/MVSep Mega 53-stem, Basic Pitch, TransKun, automatic retry, and corrupt-source-audio diagnostics remain unchanged.
