# StemScore 1.0.0-public-rc4

RC4 focuses on making the five-stage workflow easier to use and easier to recover from.

- Damaged FLAC/other source files now use FFmpeg's tolerant decode path. Recoverable bad frames are logged and skipped instead of aborting the whole project; StemScore only stops when no usable WAV can be produced.
- The stage list is switched to `running` synchronously before the worker thread starts, so the top-left workflow status no longer stays on `ready` until a second click.
- Stage 4 stems that were **not selected for dereverb** keep their original role and filename instead of being renamed with `_dry`.
- Stage 5 no longer requires Stage 4 to be fully completed/reviewed. It uses finished Stage 4 stems where available and automatically fills missing roles from Stage 3; when Stage 4 is still running it safely uses Stage 3 stems.
- Added **跳过当前步骤** and **直接运行所选步骤** controls. Direct run bypasses manual-review gates while still checking that the actual upstream files required by that stage exist.
- A project reopened after an interrupted run converts stale `running` states to a recoverable failed state instead of leaving the step permanently stuck.
- If `ffmpeg` / `ffprobe` is missing, **一键修复运行环境** installs the pinned FFmpeg package through winget and refreshes the current process PATH.
- RC3's MSST/MVSep Mega 53-stem, Basic Pitch, TransKun, SHA-256 verification and automatic runtime repair remain available.
