# StemScore 1.0.0-public-rc1

这是不含模型权重和预装运行时的公开候选版。

- 保留五步人工审查、MSST/UVR 兼容、选择性去混响、逐轨 MIDI、训练 WebUI、音乐分析、本地 Music 3 提示词和模型管理。
- RTX 40/50 使用同一应用核心和独立 profile；公开资产不包含任何 CUDA/Python runtime payload。
- 部署器可绑定用户已有且有权使用的 MSST、UVR 与转写环境；缺失必需文件时不会标记为可运行。
- 公开构建启用 `-PublicSafe`，拒绝传入 runtime payload，并扫描应用目录中的 `.ckpt`、`.pt`、`.pth`、`.th`、`.onnx`、`.safetensors` 和 `.gguf` 文件。
- RTX 50 有真实 CUDA 与五步回归证据；RTX 40 仍明确缺少实机 CUDA 回归。

安装步骤见 `PUBLIC_RELEASE_README.md` 或 `docs/StemScore-Public-Install.md`。
