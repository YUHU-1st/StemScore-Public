# StemScore 1.0.0-public-rc7

RC7 fixes audible vocal leakage in the public MVSep Mega 53-stem stage-2 accompaniment path.

- Stage 2 no longer derives accompaniment as `original mix - estimated vocals` for the public 53-stem model.
- `lead-vocal`, `back-vocal`, and `vocal` are reserved for the vocal output.
- Accompaniment is built directly from all remaining non-vocal model outputs, preventing the original vocal signal from being reintroduced by imperfect phase cancellation.
- A complete 53-stem cache is reused when stage 2 is retried, so post-processing changes do not rerun the 1.37 GB separator unnecessarily.
- Stage 3 continues to reuse the same raw 53-stem cache.

Real-project validation on the reported track reused all 53 existing stems. The old accompaniment had a strong negative zero-lag correlation with the vocal aggregate (about -0.684), consistent with subtraction-based construction; the new non-vocal mix was close to decorrelated (about 0.039). The corrected stage-2 vocal and accompaniment artifacts were regenerated without rerunning MSST.

Validation: 88 automated tests passed before release preparation.
