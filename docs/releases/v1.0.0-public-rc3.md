# StemScore 1.0.0-public-rc3

RC3 closes the clean-machine runtime gap found in RC2.

- Runtime-related failures now enable an in-app **一键修复运行环境** button.
- Repair downloads only pinned public components from official sources and verifies SHA-256 before use.
- Missing FFmpeg is repaired through the Windows WinGet `Gyan.FFmpeg` package before the AI runtime is installed.
- The public fallback separator uses `msst==0.1.0` and MVSep Mega 53 Stems v1 instead of downloading the older license-ambiguous separation checkpoints.
- RTX 50 uses PyTorch 2.8.0 / cu128; RTX 40 uses PyTorch 2.11.0 / cu126 so it remains inside MSST's `<2.12` compatibility range.
- UVR/Demucs is no longer a hard dependency of the current five-stage workflow.
- The public deployer can install a repairable client before the AI runtime exists and records `runtimeRepairRequired=true`.
- If no permissively licensed dereverb checkpoint is installed, stage 4 preserves the original stem and records that bypass instead of silently downloading a restricted model.
- After a successful repair, StemScore automatically retries the failed workflow stage.
