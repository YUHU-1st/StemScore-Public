# StemScore 1.0.0-public-rc8

RC8 修复 RC7 的重叠分轨相加导致伴奏和部分乐器轨响度过高、PCM 截顶的问题。

- 第 2 步优先选择本机已有的双输出人声/伴奏模型；其次选择已有专用人声模型。公开 Mega53 回退路径只取模型的 `vocal` 输出，伴奏由原混音计算残差，不再混合约 50 个重叠预测轨。
- 第 3 步选择每类乐器的总类输出，不再将总类与子类重复相加。中间混音使用浮点 WAV，残差写入 PCM 前按源轨的峰值和平均电平统一衰减，避免削波；日志记录实测值与增益。
- 第 4 步新增去混响响度增益质量门，候选比原轨平均电平高出 3 dB 以上时恢复原轨。
- Music 3 音乐分析不再依赖五步流程审查。打开客户端即可选歌生成 BPM/曲风/配器/结构报告与本地提示词；已有分轨只用于补充证据。
- 无分轨时不会再误称歌曲为纯音乐；本地 Qwen 精炼提示改为严格遵守报告已支持的曲风、配器和人声证据。
- 双输出 Mel-Band RoFormer Deux 权重为 CC-BY-NC-4.0，仅在用户自行安装且遵守授权条件时调用，不随公开版下载或分发。公开版默认仍只自动安装许可明确的 Mega53。

验证（2026-10-01）：

- Windows 本机完整回归测试：`python -m pytest -q`，94 项通过；覆盖双轨优先选择、Mega53 残差回退、重叠轨防削波、去混响增益门和无五步审查的独立 Music 3 分析。
- 用李荣浩《模特》12 秒本地片段和已安装的 BS-Roformer Resurrection 在 RTX 5080 上实测第 2 步：原音峰值 -0.23 dBFS / RMS -16.57 dBFS；人声 -8.60 / -20.99 dBFS；伴奏 -1.78 / -18.59 dBFS。三轨均为 12.0 秒，均无接近满幅样本。该片段只用于本机验证，不包含在发布资产中。
- 独立 Music 3 流程在五步均未执行的项目上生成 5 份分析/提示词文件；已安装的本地 Qwen2.5 7B GGUF 精炼返回 `applied=true`。无分轨时明确标注人声未知，不再错误断定为纯音乐。
- 本机 PyInstaller 冻结客户端成功启动；公开 GPU 发布脚本生成核心包、RTX 40/50 配置包、部署脚本、第三方声明和 SHA-256 清单，共 11 个文件。
- Mega53 公开权重已下载并通过固定 SHA-256 校验；因测试时用户的 ComfyUI 正在占用 GPU，未在本轮强行运行 Mega53 CUDA 推理。公开回退路径有自动化模拟测试，但真实模型音质仍须在显存空闲时听审，不能由本次验证推断已达标。
