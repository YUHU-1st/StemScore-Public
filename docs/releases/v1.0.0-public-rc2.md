# StemScore 1.0.0-public-rc2

这是公开候选版 RC2，修复全新 Windows 机器上的安装与部署行为。

- Basic Pitch 可在尚未提供 MSST 时独立安装和验证；之后可用 `-MsstRoot` 补装 TransKun。
- Windows PowerShell 5.1 下，原生命令写入 stderr 的正常警告不再被误判为安装失败。
- 公开部署器在没有内置 runtime 且未同时提供 MSST、UVR、Transcription 三个运行时根目录时直接停止并给出明确错误，不再生成容易被误认为可运行的半成品安装。
- 外部 runtime 会逐项校验 MSST Python、推理入口、四组核心配置/权重、Demucs 模型目录、Basic Pitch 模型和 TransKun 权重。
- 公开构建继续保持 `publicSafe=true`，不包含许可未确认可再分发的 MSST/UVR 分离权重。
- 模型管理器仍支持 CLAP、Qwen2.5 GGUF 与固定 llama.cpp runner 的本地下载安装、断点续传和 SHA-256 校验。

本版本基于 `main` 的修复提交构建，并重新生成 Release 清单和 SHA-256。
